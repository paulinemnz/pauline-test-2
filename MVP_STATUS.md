# France Industrial Water-Risk Cockpit

The local MVP is implemented in `water-risk-cockpit/`.

Current prototype capabilities:

- France-focused industrial water-risk dashboard
- Portfolio-level risk and exposure indicators
- Facility map concept and ranked diligence queue
- Local development preview with no API keys required

The current version is an early product slice. Editable facility assumptions, verified public-data snapshots, CSV import, automated risk tests, and deployment remain planned follow-up work.
